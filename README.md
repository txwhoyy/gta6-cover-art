A GTA 6-style cover art maker: drop in your own photos, lay them out across bold poster panels, add a caption, apply a Vice City sunset or neon grade, and export a shareable PNG — 1080×1080, 1080×1350 or 1920×1080. Fully offline, no build step.

## Run it

```sh
node serve.ts
```
